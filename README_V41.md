# BTC V4.0.1 Telegram Bot - 部署指南

## 🚀 V4.0.1 核心升级

**从V4.0到V4.0.1的重大升级**:

### ✨ 新特性
- **V7.0"掠食者"引擎**: Robust Z-Score + Δ²LS二阶导数 + 三级预警系统
- **市场环境过滤器**: 自动判断牛市/熊市/震荡，牛市阶段跳过做空预警
- **准确率大幅提升**:
  - 7天准确率: 85.7% (vs V4.0的66.7%)
  - 30天准确率: 100.0% (vs V4.0的66.7%)

### 📊 预警系统
**三级预警分级**:
- **LEVEL 1 (Score 70-80)**: 观察 - 市场活跃
- **LEVEL 2 (Score 80-90)**: 警戒 - 物理极脆
- **LEVEL 3 (Score >=90)**: 坍塌预警 - 强烈预警信号

**市场环境过滤**:
- **牛市** (价格涨>10%): 跳过做空预警，避免亏损
- **熊市/震荡**: 正常执行所有预警

## 🎯 使用建议

### 保守型策略 (推荐)
- 只执行LEVEL 3预警
- 牛市完全跳过做空
- 熊市/震荡坚决执行
- **预期准确率**: 85.7% (7天), 100% (30天)

### 激进型策略
- 执行LEVEL 2/3预警
- 牛市降低仓位执行
- **预期准确率**: 较低，但机会更多

### ImportError: No module named 'btc_v70_predator_engine_fixed'
**原因**: 缺少V7.0引擎文件
**解决**: 确保 `btc_v70_predator_engine_fixed.py` 和 `market_filter.py` 在同一目录

### 预警不准确
**原因**: 市场环境变化
**解决**:
1. 观察至少30天
2. 记录实际结果到日志文件
3. 对比回测准确率
